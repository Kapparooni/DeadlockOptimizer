This repo is for my personal powershell script that starts the game while replacing the current configs gameinfo.gi as well as video.txt with custom ones, since they are wiped every time the game updates (it updates very often).

The configs I used were directly taken from https://github.com/Sqooky/OptimizationLock these can be edited or changed to whatever one might desire.

Important to note that you have to manually set the path to the custom configs as well as the destination folders within the Deadlock Steam folder.
